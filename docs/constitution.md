# Constitution
1. Preserve the agreed product scope; record unresolved decisions instead of inventing approval.
2. Keep one deployable backend and enforce inward Clean Architecture dependencies.
3. Keep graph and scheduling logic deterministic and independent of I/O.
4. Maintain requirements, implementation and verification evidence together.
5. Protect user data; use explicit ownership rules before public multi-user persistence.
6. Use English engineering artifacts and a responsive ES/EN user interface.
7. Prefer small, testable use cases and measured improvements over speculative infrastructure.
8. Treat failed or unexecuted checks honestly; completion requires relevant passing evidence.
